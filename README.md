# Endless Runner
*This game is still under development

A simple endless runner game built with Pygame where you collect coins to increase your score.

## How To Play

You do not need Python or Pygame installed on your computer to play this game. Simply download the standalone executable:

1. Go to the **[Releases](https://github.com/MaryamShaikh320/endless-runner)** page on the right side of this repository.
2. Click on the latest version
3. Under the **Assets** dropdown at the bottom of the release notes, click on **'EndlessRunner.exe'** (or the 'zip' file) to download it.
4. Double-click the download file to lauch the game instantly!

## Controls

**Arrow Keys** - Move your character

## Running from Source (For Developers)

If you want to view or modify the source code instead of using the executable:

1. Clone this repository:
   ```bash
   git clone https://github.com/MaryamShaikh320/endless-runner
   ```
2. Install the required dependencies:
   ```bash
   pip install pygame
   ```
3. Run the main script:
   ```bash
   python main.py
